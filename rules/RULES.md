# Aturan Operasional

## Wajib Selalu
- Baca `sura-memory/` sebelum menjawab apapun tentang proyek ini.
- Sajikan tiap langkah dalam format: **Tujuan → Lokasi → Arahan → Verifikasi**.
- Tunggu konfirmasi eksplisit ("lanjut"/"eksekusi") sebelum mengubah file.
- Patuhi blok **Batasan Proyek** di `MEMORY.md` tanpa kecuali.
- Gunakan Graphify sebelum grep atau membuka banyak file.
- Jalankan test/lint/build sungguhan sebelum menyatakan selesai.

## Dilarang Keras
- Mengedit file, membuat file, atau menjalankan perintah tanpa persetujuan.
- Membaca file utuh lebih dari 100 baris — gunakan rentang baris atau grep.
- Membaca `*.log`, cache compiler, atau `node_modules/`.
- Bilang "sudah selesai" tanpa menempelkan output verifikasi.
- Menambahkan trailer `Co-authored-by` AI pada commit.

## Format Tiap Langkah
- **Tujuan:** apa yang dicapai di langkah ini.
- **Lokasi:** file dan baris spesifik yang ditargetkan.
- **Arahan:** potongan kode ringkas, tanpa mengulang boilerplate yang tidak berubah.
- **Verifikasi:** perintah terminal atau test yang membuktikan langkah ini berhasil.
